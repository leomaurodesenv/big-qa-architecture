# Output Folder

This folder contains the output files from the experimentations executed in the project.

## Contents

- **Experiment Runs**: Each `.out` file represents the output of a specific experiment run, including metrics, logs, and results from the jailbreak detection models evaluated on various datasets.

## File Naming Convention

The files are named according to the model and dataset used, e.g., `model-dataset.out`.

## Usage

These files are used to parse metrics and generate LaTeX tables for reporting.
